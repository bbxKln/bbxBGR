一个带 REST API 的 桌游场次纪录 应用，支持登录，支持移动端查看
# 基本功能
用户可以创建账号，登录应用。每个用户有自己用户id。
在大厅内可以创建桌游群组，可以在群组内添加桌游场次纪录。
另有分析界面，可以看胜率
还可以添加好友到群组内，群组内的用户都可以共享分析群组内的桌游纪录
另外会需要API，暂时不要创建，未来会描述需要的API，但是设计的时候需要留下API的空间
同步到github。上线使用cloudflare全家桶

## 具体功能描述
- 基本的登录功能
- 创建桌游群组。登录后应该是空白的，有一个默认的+号卡片。每个群组都是一个卡片
  - 每个玩家都可以看到自己已经加入过的群组
  - 新增群组后会有一个群组id，这个id只有管理员角色可以看到。其他玩家可以在主页面通过群组id进入一个群组。id是简单的8位数字
- 桌游群组内的功能：
  - 创建桌游的玩家为admin角色。
  - 新增桌游的功能
    - 桌游有标签功能
  - 新增玩家的功能
    - admin可以分配admin_user权限给其他玩家
    - 玩家信息：姓名（必填），用户id（选填）
    - 只有admin和admin_user可以修改用户id
    - 添加用户id后，该用户登录的时候就会默认看到这个群组
  - 新增桌游场次的功能
    - 新增桌游场次需要提供以下信息：桌游名称，游玩时间（默认今天），参与玩家（多选），获胜玩家（多选），评论
    - 参与的玩家可以通过自己的账号留下并编辑属于自己的评论
  - 分析功能
    - 可以按照时间维度分析玩家胜率（可添加桌游和标签筛选项）
    - 可以按照玩家维度分析各个桌游胜率
